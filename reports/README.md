# Report generation

Reports are generated by the Python package in `src/vlad/reporting/`:

```bash
vlad report --kind randomise --results-dir /path/to/cohort/Results/Analysis \
  --analysis-name Analysis --matrix-name Model --permutations 500
```

Use `--kind swe` for longitudinal mixed-model summaries. The normal VLAD
workflow selects the kind automatically. HTML includes its images and styles;
JSON, Feather and SVG exports record the numerical summaries and merged data.

Generated study reports belong in the cohort's results/export directories.
The historical R templates are archived under `reference/r/` and are never
executed by the active workflow.
